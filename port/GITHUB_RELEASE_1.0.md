# Moraff's World Native Port 1.0

The first complete release of the unofficial native Windows preservation port
and optional Enhanced Edition of **Moraff's World**, created by Steve Moraff
and published by MoraffWare.

## Highlights

- Native 64-bit Windows executable with the original 1024×768 four-viewport
  presentation
- Classic 251-floor mode and optional Enhanced 1,000-floor mode
- Original-style dungeon rendering, map revelation, monsters, combat, magic,
  equipment, shops, wilderness, boats, title sequence, and character creation
- Enhanced late-game floors, enemies, bosses, equipment, spells, relics, and
  quests
- Bestiary, game statistics, native trainer, mouse controls, and model viewer
  with grouped palette variants and full-screen inspection
- Local, portable installation with no installer or registry dependency

## Installation

Download and extract `Moraffs-World-Native-Port-1.0-win64.zip`. You must then
copy the ten required files from your own legally obtained original Moraff's
World installation into the extracted directory:

`MW.EXE`, `WORLD.EXE`, `DUNG.BIN`, `WORLDMAP.BIN`, `H.BIN`, `WORLD.PIC`,
`WALL.PIC`, `360X480.FNT`, `320X200.FNT`, and `ROLL.TXT`.

The release does **not** redistribute those original files. Exact requirements
and checksums are documented in the included
`ORIGINAL_FILES_REQUIRED.md`.
