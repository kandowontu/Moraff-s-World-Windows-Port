# Moraff's World Native Port 1.0.1

This revision expands original-game compatibility while retaining strict
integrity validation.

## Changes

- accepts both approved original `WORLD.EXE` distribution variants
- validates `MW.EXE` and `WORLD.EXE` against exact file size, CRC-32, and
  SHA-256 together
- retains all Version 1.0 Classic, Enhanced, Beastiary, trainer, wilderness,
  model-viewer, combat, magic, and interface functionality
